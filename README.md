# Twotris
A local multiplayer Tetris clone. It's intense and possibly even friendship-breaking! 

## Description
2D local multiplayer video game based on Tetris. You and a friend square up, trying to catch as many blocks as you can! Each of you have your own tetris board – you have to fight to fill it more than your opponent.

## Available on Itch
Whilst the itch.io version is probably slightly out of date, it's right here: https://nillsnow.itch.io/twotris

Made in Unity 2019.4.31f1
